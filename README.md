# Vinix Analyze Dataset

## Titanic Dataset Analysis

This project was completed as part of my **Vinix Technologies AI & Machine Learning Internship**.

The project focuses on analyzing the Titanic dataset using Python and identifying patterns related to passenger survival.

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Analysis Performed

* Dataset overview and structure
* Missing value identification
* Survival analysis
* Survival by gender
* Survival by passenger class
* Age distribution
* Fare analysis
* Survival by embarkation location
* Combined analysis of passenger class and gender

## Key Findings

* 342 passengers survived, while 549 did not.
* Female passengers had a significantly higher survival rate than male passengers.
* 1st-class passengers had a higher survival rate than 2nd- and 3rd-class passengers.
* Survivors paid a higher average fare than non-survivors.
* Missing values were identified in several columns.
